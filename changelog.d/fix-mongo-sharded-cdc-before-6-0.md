- **MongoDB CDC on a sharded cluster of 4.4 or 5.0 failed to open its change stream.** rivet asked every stream for pre-images (`fullDocumentBeforeChange: WhenAvailable`), and a sharded cluster before 6.0 refuses that option with error 51771 (`the 'fullDocumentBeforeChange' option is not supported in a sharded cluster`), so every run on such a cluster stopped before reading a change. **Now** the request goes out only when the server reports 6.0 or later (or when its version could not be read); on 4.4 and 5.0 the stream opens without it and runs in the current-state tier the docs describe (deletes carry `_id` only). Servers 6.0 and later, and replica sets of any version, deliver exactly what they delivered before. **Changed behaviour:** a sharded 4.4 or 5.0 cluster that could not run CDC now runs it; nothing that worked changes. **What to do:** nothing; for pre-images on delete, upgrade to 6.0 and enable `changeStreamPreAndPostImages` on the collection.
