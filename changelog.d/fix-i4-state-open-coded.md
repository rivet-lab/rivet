- **A SQLite state file that cannot be opened stopped with no code.** Behaviour change. A `RIVET_STATE_URL=sqlite:<path>` (or a state beside the config) whose file or directory cannot be opened stopped with a bare `unable to open database file` and no `RIVET_*` code. **Now** the stop is `RIVET_STATE_NOT_WRITABLE`, naming the path and the driver's reason; the exit class follows the code (exit 1, retry decided by the cause). State written before the upgrade is untouched. **What to do:** make the state file and its directory writable, or point `RIVET_STATE_URL` at a writable path.
