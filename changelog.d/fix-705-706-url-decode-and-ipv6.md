- **An `oracle://` service name or a `sqlserver://` database written percent-encoded reached the driver with its `%XX` bytes, and a `sqlserver://` bracketed IPv6 host without a port was refused (#705, #706).** `oracle://u:p@h/ORCL%2Edomain` connected to a service literally named `ORCL%2Edomain`, and `sqlserver://u:p@h/Sales%20DB` to a database literally named `Sales%20DB`, so a URL built by an encoder failed with a listener or `Cannot open database` error; `sqlserver://u:p@[::1]/db` stopped with `mssql url port not a number: 1]`. **Now** both parsers share one percent-decode and one bracket-aware host/port split: the service and the database are decoded like the user and password, and a bracketed host without a port defaults to 1433. **Changed stop:** an Oracle service name that holds `/` after decoding (`a%2Fb`) is refused with `RIVET_CONFIG_SOURCE_URL_INVALID` as a raw `/` already was. **What to do:** nothing for a service or database written plain; a name that really holds a literal `%` must now be written `%25`.
