- **The Airflow recipe published the Airflow web UI (port 8080) and Flower (port 5555) on every network interface.** Anyone on the same network could open them with the recipe's default credentials. **Now** `docs/recipes/airflow/docker-compose.2.10.yaml` publishes both on `127.0.0.1` only; the recipe still reaches the source databases and object stores through `host.docker.internal`. **What to do:** open the UI from the machine that runs the recipe; to reach it from another host, forward the port (`ssh -L 8080:127.0.0.1:8080 <host>`) or edit the `ports:` entry.
