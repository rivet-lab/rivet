- **A PostgreSQL column of a type with no Arrow mapping is now delivered as the server's text, not refused with `RIVET_TYPE_UNSAFE_MAPPING` (behaviour change).** Through the previous release a batch export of `inet`, `cidr`, `macaddr`, `macaddr8`, `bit`, `varbit`, `money`, `"char"`, `timetz`, `xml`, `tsvector`, `tsquery`, a geometric type, a range or multirange, `regclass`, `regtype`, `xid`, `pg_lsn`, `tid`, a composite, an extension type, or an array of any of them stopped before any file was written, naming the column and asking for a `columns:` declaration. **Now** such a column is a `string` column (`Utf8`, labelled `rivet.text_form = server_text`) holding the text the server prints for the value (for example `10.1.2.3`, `[1,10)`, `(1.5,-2.25)`, `$1,234.50`), NULL where the source is NULL, in every batch mode and under `--strict`; CDC already delivered these columns as the server's text. The batch session is fixed to `datestyle ISO, MDY`, `TimeZone UTC`, `extra_float_digits 3`, `intervalstyle postgres` and `bytea_output hex` while it reads such a column, so the text does not change with the role's settings; `money` is printed in the server's `lc_monetary`. A bare `numeric` is still refused, and a column declared in `columns:` keeps its declaration. `bit` and `bit varying` in a CDC export are still refused (`test_decoding` prints `B'110'` where the server prints `110`), and the refusal now says batch delivers them as text. Tables and state written before the upgrade are untouched: an export that was refused wrote nothing, and an export that declared the column in `columns:` reads and delivers it as declared. **What to do:** nothing; to keep a refusal, or to get a typed column, declare the column in `columns:`; a downstream table that expected the column typed reads it as a string. `rivet load` takes such a column as a string on ClickHouse, BigQuery, Snowflake and DuckDB; before this change the load planner refused it with `RIVET_LOAD_COLUMN_TYPE_UNSUPPORTED`, because it read the type without its text delivery.
