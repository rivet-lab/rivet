- **Harness: every image the stand and the release gate run is pinned as `tag@sha256:<index digest>`.** The tag names the version the gate host ran, the digest the exact build; a registry that moves a tag no longer changes what the gate grades. The pins are in `docker-compose.yaml`, `dev/stand/docker-compose.yaml`, `dev/release-oracle/matrix.yaml` and the `*IMAGE` constants of `dev/`. `tests/offline/compose_image_pins_guard.rs` fails when an image lacks its digest or one tag carries two digests, and keeps a dated ledger for the three repos pinned by digest alone (minio, pgbouncer, azurite). The gate now writes every running container's image and RepoDigest to `release-oracle-images.json` (`--images-file` names another path). No product behaviour changes. **What to do:** nothing; to move a pin, change the digest in one place per file and re-run `make test-offline`.
