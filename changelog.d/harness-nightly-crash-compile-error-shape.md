- **The nightly delta graded `nightly[crash|compile error]` NEW from a child's own refusal: the gate echoes a failed read of an old field release (`error: unexpected argument '--clickhouse-url' found`) into its stderr, and the crash marker matched every line that starts with `error: `.** **Now** a compile error is read by cargo's own shapes (`error[Exxxx]: `, `error: could not compile`, `aborting due to`, `failed to run custom build command`, `linking with`), so a child's refusal no longer reads as a crash. **What to do:** nothing.
