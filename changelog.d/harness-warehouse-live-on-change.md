- **Every `make test-live` and dev release-oracle run billed BigQuery and Snowflake, even when no warehouse code changed.** **Now** a run outside the release gate fills a warehouse's env only when the branch changed that warehouse's loader, client or test code (or a shared load path) since `origin/main`; other runs print `bigquery legs SKIP` / `snowflake legs SKIP` with the reason. The full and island release gates always run both. **What to do:** set `RIVET_WAREHOUSE_LIVE=bigquery`, `snowflake`, `all` or `none` to override the choice outside the gate.
