- **`dev/pytools/release.py` could tag only the exact commit the gate graded, so a harness-only commit after a green gate needed a new full gate.** **Now** `--graded-sha A` tags a descendant whose diff touches only harness, test and docs paths and whose release binary has exactly the SHA-256 the gate recorded for A (`binary_sha256` in `timings.jsonl`); a record without the hash, another path or a different hash keeps the refusal. `docs/release-checklist.md` also states which reds block a tag. **What to do:** nothing; build the descendant with `RIVET_GIT_SHA` set to A's stamp when using the flag.
