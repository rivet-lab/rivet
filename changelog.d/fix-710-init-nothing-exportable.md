- **`rivet init` refuses a scaffold that would hold no export.** `init --mode cdc` on Oracle, when every table it found could not be mined (a LOB column, a name over 30 bytes, ...), wrote a `rivet.yaml` with only `# SKIPPED` comments and an empty `exports:` that rivet then failed to load as a config (0.32.2 and earlier). **Now** init stops with `RIVET_INIT_NOTHING_EXPORTABLE` (exit 5), names each table with its skip reason, and writes nothing. **What to do:** fix what the reason names, re-run init with another `--mode` (a batch init of the same tables works), or `--include` a table it can export.
