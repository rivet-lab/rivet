- **`rivet init` refuses a scaffold that would hold no export.** A MongoDB init where every collection name fails the `table:` identifier gate wrote a `rivet.yaml` with only `# SKIPPED` comments and an empty `exports:`, which rivet then failed to load as a config (0.32.2 and earlier). The unreleased Oracle CDC skip of tables LogMiner cannot mine (a LOB column, a name over 30 bytes, ...) did the same for `init --mode cdc`. **Now** init stops with `RIVET_INIT_NOTHING_EXPORTABLE` (exit 5), names each table with its skip reason, and writes nothing. **What to do:** fix what the reason names (an Oracle CDC skip clears with a batch `--mode`), or `--include` a table it can export.
