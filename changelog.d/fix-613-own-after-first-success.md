- **A failed first load counted as ownership of a table rivet never created (#613).** A first load that failed or died mid-write left a `failed` or `writing` ledger row, and that row alone made the target rivet's own. On BigQuery, ClickHouse and Snowflake such a load can fail before the target name exists, so a table someone else created before the retry was overwritten, or adopted as a change log, without the `RIVET_LOAD_TARGET_NOT_RIVETS` refusal. **Now** a table is rivet's own only after a load into it succeeded with runs consumed; a later failure does not disown it. **Changed stop:** a retry after a first load that never completed, onto a table that exists, now refuses with `RIVET_LOAD_TARGET_NOT_RIVETS` (exit 5) instead of loading. **What to do:** if the table is what that first load left, drop it and re-run; that load consumed no run, so the next load delivers its rows again.
