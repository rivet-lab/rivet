- **`rivet schema cli` had no machine-readable list of the commands and what each one must guarantee.** Test matrices kept their own hand-written lists of commands. **Now** every leaf command has one role in a single table, and `rivet schema cli --json` prints each leaf with its role, the executor a pre-run command pairs with, and which of the five product invariants apply to it; a new command without a role does not compile.
