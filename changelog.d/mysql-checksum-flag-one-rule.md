- MySQL: the value checksum of a flag column (`TINYINT(1)`, a `bool` override, `BIT`) reads a cell by the same rule delivery and the stream use: 0 is false, 1 is true, any other value is no flag. Before, the checksum read an integer as true for every nonzero value and a text cell (`0` included) as true, so a value delivery refuses would have been graded as true. Delivery and the exit code are unchanged; no state or table written before the upgrade is affected.
