- **MySQL: the value checksum of a flag column (`TINYINT(1)`, a `bool` override, `BIT`) read a cell by its own any-nonzero rule while delivery reads 0 and 1 only.** A text `0` was checksummed as true, and a value delivery refuses (`2`, `-1`, `255`, `BIT(8)` 5) was checksummed as true, so integrity would have been graded against a value the file does not hold. The checksum, delivery and the stream now read a flag by one rule: 0 is false, 1 is true, any other value is no flag. Delivery and the exit code are unchanged; no state or table written before the upgrade is affected.
