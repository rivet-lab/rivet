- **An unreachable source stopped with no code.** Behaviour change. A run whose source host does not resolve, refuses the port, times out, or refuses the login stopped with the driver's words and no `RIVET_*` code on PostgreSQL, MySQL, SQL Server, Oracle and MongoDB. **Now** every such stop is `RIVET_SOURCE_CONNECT_FAILED`, with the same words after the code. The exit class is unchanged for these stops (exit 2 when the cause is transient, otherwise 1); a scheduler that matched the words can match the code. Files, state and tables written before the upgrade are untouched. **What to do:** nothing; match `RIVET_SOURCE_CONNECT_FAILED` instead of the driver text.
