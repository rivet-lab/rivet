- **A MongoDB `_id` column that held ints, strings or a mix was labelled `rivet.native_type: objectid` and `rivet.fidelity: exact` in the Parquet field metadata (#996).** The label was fixed in the code, so a reader of the file could take the flat text for a typed ObjectId key. **Now** the label follows the collection: all-ObjectId (and empty) collections keep `objectid` / `exact`; any other `_id` set is labelled `bson_id` / `logical_string`. **Changed label:** a consumer that matched `rivet.native_type == objectid` on a non-ObjectId collection no longer matches. **What to do:** nothing for ObjectId collections; for others read `bson_id` as "BSON `_id` rendered as text". A `columns:` override on a Mongo `_id` is refused with `RIVET_SOURCE_OVERRIDE_WIRE_MISMATCH` (pinned, see #915).
