A SQL Server `query:` export keyed on `datetime2(7)` is not covered yet. **What to do:** declare the column `timestamp_ns` under `columns:` (or name a `pk:` that does not depend on it), `rivet state reset --export <name>`, run and reload; tables already loaded keep their column type, so drop the change log and view first.
