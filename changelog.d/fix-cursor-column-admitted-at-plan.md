- **Behaviour change: an incremental `cursor_column` that can hold NULL, or whose type the cursor cannot render, is now refused at plan time on PostgreSQL, MySQL, SQL Server and Oracle.**
  Before, a nullable `cursor_column` without `incremental_cursor_mode: coalesce` exported the rows whose cursor was NULL on the first run and never again: a row inserted later with a NULL cursor was lost, with exit 0. A cursor column of a type the cursor cannot render (boolean, time of day, binary, array, a timestamp unit other than microsecond or nanosecond) logged a warning, exited 0 and re-exported the whole table on every run.
  **Now** `rivet check`, `validate`, `plan`, `run` and `apply` (and every partition child) stop before any read: a nullable cursor ends `RIVET_PLAN_CURSOR_NULLABLE` (exit 5), an unrenderable one `RIVET_PLAN_CURSOR_TYPE_UNSUPPORTED` (exit 5); the message names the column and the cause. Nullability is the server's own description of the export query (the catalog `NOT NULL` of the base column on PostgreSQL, the column flag on MySQL, `sp_describe_first_result_set` on SQL Server, the describe metadata on Oracle, confirmed against the catalog of the one table the query reads on SQL Server and Oracle); a column it cannot trace to a table column (an expression over NOT NULL columns, a view column on PostgreSQL, a SQL Server or Oracle query over a join or a subquery) is not claimed either way, and a source that cannot be reached for the check is warned about and not refused. A NOT NULL cursor of a supported type, a nullable primary under `coalesce`, and decimal, text, date, uuid and timestamp cursors run as before.
  **What to do:** make the cursor column NOT NULL (`ALTER TABLE ... SET NOT NULL` once no row holds NULL), or set `incremental_cursor_mode: coalesce` with a NOT NULL `cursor_fallback_column:`; changing the mode changes the progress identity, so run `rivet state reset -c <config> --export <name>` once (the next run re-exports the table). For an unrenderable type use an integer, text, date, timestamp or uuid column, or `mode: chunked` / `full`.
