- **A zero `batch_size`, an empty or NUL destination `path`, an export name over 200 bytes and a source URL of another engine's scheme are refused when the config is read.** Behaviour change. Before, `rivet check`, `validate`, `metrics` and `journal` accepted them (exit 0), `batch_size: 0` ran as 1, and `plan`, `load`, `compact`, `reconcile` and `repair` stopped at their own precheck before naming the config error; MongoDB accepted all four. **Now** every command stops with `RIVET_CONFIG_VALUE_OUT_OF_RANGE`, `RIVET_CONFIG_PATH_UNSAFE` or `RIVET_CONFIG_SOURCE_URL_SCHEME_MISMATCH` (exit 1) before it connects. The URL scheme is checked at load for an inline `url:`, a set `url_env` and a readable `url_file`; an unset variable is still reported when the run resolves it. Files, state and tables written before the upgrade are untouched. **What to do:** write `batch_size: 1` or more (or drop it), give `path:` a directory, shorten the name, and make `source.type` match the URL scheme.
