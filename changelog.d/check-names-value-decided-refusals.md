- **`rivet check` says which refusals it cannot decide.** Before, `rivet check` exited 0 on an export whose run then refused a value with `RIVET_SOURCE_VALUE_UNREPRESENTABLE` or `RIVET_LOAD_VALUE_OUT_OF_TARGET_RANGE`, with no hint that check reads no values and so cannot see them. **Now** check prints `note[values-unread]: rivet check reads no values; a run may still refuse a value with RIVET_SOURCE_VALUE_UNREPRESENTABLE, RIVET_LOAD_VALUE_OUT_OF_TARGET_RANGE` on stderr; its exit code and stdout are unchanged. `docs/reference/errors.md` lists these codes under "Decided by a value". **What to do:** nothing; a script that parses check's stderr should skip lines starting with `note[`.
