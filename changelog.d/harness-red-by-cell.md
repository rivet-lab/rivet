- **The paired gate report marked every live red NEW and moved a red between runs when the slice cut moved it.** A live cell red in a slice collapsed into one key per slice (`nightly[gate|live/-] FAIL`), and gate-history keyed an exit by its slice number, so the same red in a different slice read as a new one. **Now** a red is keyed by its cell (`module::test`) in `paired_report`, `nightly_delta`, `gate_history` and the ledger (`known_red.cell_of`, `cell_key`, `cells`); the ledger match on that key alone decides KNOWN or NEW, a NEW red that the previous run held in another slice is MOVED (`--prev-run-id`, default the run before it), and a warning heading a cell's first line no longer changes its key. The first gate-history line after this change differs from the one before it in every live red key.
