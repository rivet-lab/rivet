- **`cleanup_source` now deletes a CDC stream's staged baseline when the baseline is loaded alone.** On a `layout: base_buffer` CDC load, only the change-stream leg cleaned its staged files; a first load whose stream had nothing to buffer (an idle drain) landed the baseline in the base and left `cdc/<table>/snapshot/...` at the destination until a later load buffered changes (0.32.2 and earlier). **Now** the baseline leg cleans under the same rules when no buffer leg follows: only the runs this load consumed, never a run still writing, under the prefix lease. **What to do:** nothing; a baseline left by an earlier load is cleaned by the next load that buffers changes, as before.
