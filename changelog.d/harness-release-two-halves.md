- **A tag could rest only on one `release-oracle-full` line from one machine, and the hosted half's verdict job went red whenever its slices had each built their own binary.** **Now** `python3 -m dev.pytools.release --halves` takes the gate from two halves: the devbox half's `release-oracle-full-devbox` line and the hosted half of a finished, wholly green `gate-hosted` run on main (fetched with `gh`, or `--hosted-record DIR`), each built from the same full sha, clean, together running every stage of the gate once; anything missing, stale, partial or from another workflow, fork or branch refuses with a `HALVES_*` code. Every gate record now names the stages it ran and its host, and the hosted verdict job writes one `hosted-verdict` artifact. Without `--halves` the tag path is unchanged. **What to do:** nothing.
