- **`rivet check` now asks a CDC export's prerequisites, and a SQL Server capture instance is judged by column name (behaviour change).** Through the previous release `check` read no CDC prerequisite at all (only `doctor` and `run` did), the SQL Server prerequisite answered "met" for every server, and the row image of a capture instance was judged by the count of its captured columns, so a column added and a captured column dropped read as a whole image while the added column was never captured. **Now** `check`, `doctor` and `run` ask one function before any anchor or snapshot part is written; on SQL Server it refuses with `RIVET_SOURCE_CDC_PREREQUISITE` (exit 5) a capture instance that does not carry every column of its table, counted by name, and `check` stops with that refusal (or the source's connect error) where it used to print "Looks good". **What to do:** re-enable the table's CDC with the full column list (omit `@captured_column_list`) and re-baseline.
