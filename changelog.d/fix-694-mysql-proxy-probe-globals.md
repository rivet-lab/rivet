- **The MySQL proxy probe reads its two global variables in one statement.** At connect time rivet 0.32.2 read `version_comment` and `proxy_version` with two `SHOW GLOBAL VARIABLES LIKE` statements. Each one scans the full variables table: about 634 rows on MySQL 8.0, about 1267 for the pair. The CDC perf gate saw that as `Handler_read_rnd_next` with no user table read. **Now** one `SHOW GLOBAL VARIABLES WHERE Variable_name IN (...)` reads both: 2 rows on MySQL 8.0.46. On MySQL 5.7 every form of this statement scans the table (1012 rows), so the probe's cost there halves. There is still no `@@` read, so ProxySQL keeps multiplexing the session.
