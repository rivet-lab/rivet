- **The hosted half of the release gate only ran when somebody started it, and left no record of the nights between runs.** **Now** `.github/workflows/gate-hosted.yml` also runs on a schedule on the head of main (a night with no new commit is skipped), and a `history` job appends one line per graded run to `history.jsonl` on the `gate-history` branch (verdict, test counts, self-skips, minutes per slice, red keys, and the new and fixed red keys against the previous line of the same ref) with the run's own token; only that job holds `contents: write`, nothing is ever pushed to main, and a failed write never fails the run the tag reads. Every line names the ref it was graded under (`ref`, `ref_name`, `ref_type`, `event`, `run_id`, `run_url`, and `workflow_sha` when it is not the graded sha), its key is sha + ref + run id, and `gate_history.py show --ref X|--sha Y` prints the lines; the run name, every check run of the hosted half, the verdict artifact (`hosted-verdict-<ref>`) and the verdict job summary carry the ref. **What to do:** nothing; a hosted run made before this change is not read by `release.py --halves` (its job and artifact names carry no ref), dispatch a new one.
